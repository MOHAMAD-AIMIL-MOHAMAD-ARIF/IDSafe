## 1. Installation (Clone repository)

```bash
git clone https://github.com/MOHAMAD-AIMIL-MOHAMAD-ARIF/IDSafe.git
cd idsafe
```

## 2. Renaming Environment Files
Please rename these files before running the system:
1. "C:\\...\IDSafe\backend\\.env(sample-for-local-development).txt"
   into: .env
2. "C:\\...\IDSafe\frontend\env.local(sample).txt"
   into: .env.local

## 3. Setup (Backend)
```bash
cd backend
npm install
npm run dev
```

## 4. Setup (Frontend)
```bash
cd frontend
npm install
npm run dev
```

## 5. Access the landing page
Open a web-browser and enter this address: http://localhost:3000
