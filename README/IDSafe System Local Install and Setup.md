## 1. Installation (Clone repository)

```bash
git clone https://github.com/MOHAMAD-AIMIL-MOHAMAD-ARIF/IDSafe.git
cd idsafe
```

## 2. Setup (Backend)
```bash
cd backend
npm install
npm run dev
```

## 3. Setup (Frontend)
```bash
cd frontend
npm install
npm run dev
```

## 4. Access the landing page
Open a web-browser and enter this address: http://localhost:3000
